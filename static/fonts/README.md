# Шрифт интерфейса

Интерфейс набран **HSE Sans**. Шрифт корпоративный, в комплект приложения
не входит — положите сюда лицензионные файлы:

```
HSESans-Regular.woff2   (или .woff)
HSESans-Bold.woff2      (или .woff)
```

Имена важны: на них ссылается `@font-face` в `../style.css`.

Если шрифт установлен в системе, файлы не нужны — `@font-face` сначала
пробует `local("HSE Sans")`. Если нет ни установленного шрифта, ни файлов
здесь, правило молча отваливается и интерфейс рисуется системным гротеском;
ничего не ломается, меняется только начертание.

Конвертировать ttf/otf в woff2 можно так:

```bash
pip install fonttools brotli
fonttools ttLib.woff2 compress HSESans-Regular.ttf
```
